## 👋 你好，我是鼠标炸弹 · Hi, I'm Mousebomb

八零年代末出生的水瓶座，典型的网虫、工作狂、Geek。硬核科幻小说、电影、游戏、软件是我的快乐源泉。<br>
Born in the late 80s, Aquarius. A typical web junkie, workaholic and geek. Hardcore sci-fi novels, movies, games and software are my sources of happiness.

**职业生涯 · Career Highlights**

- 🎨 **2006 – 2010** · Flash 网站开发，作品在网上大量被传阅和转载
  - Built Flash websites that were widely shared and reposted across the web
- 🎮 **2010 – 2017** · 3D MMO 页游开发，写过 3D 地形编辑器、游戏框架、Away3D 等引擎定制
  - 3D MMO web game development: built a 3D terrain editor, game frameworks, and customizations for engines like Away3D
- 📱 **2014 – 2017** · 手机单机小游戏广告变现，自研自动生成游戏引擎，赋能整个团队，累计 **1 亿 +** 下载，帮团队好几个成员实现了上百万收益
  - Mobile casual games monetized with ads; built an auto game-generation engine that empowered the whole team — **100M+** downloads, generating millions in revenue for several team members
- 🚀 **2017 – 至今** · 全栈开发，重度拥抱 AI 协作，快速打磨各种产品和工具
